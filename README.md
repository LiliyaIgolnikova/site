# site
**Сайт-визитка юриста. Используются языки PHP, MySQL. На сайте есть форма заявки, отзывы, отправка писем на email**
# Стек технологий:
- HTML
- CSS
- PHP
- MySQL
# Как запустить проект:
1. Склонируйте репозиторий
2. Откройте файл "index.php" через браузер с помощью локального сервера
# Возможности программы:
1. Форма отправки заявки на электронную почту
2. Сохранение отзывов в базе данных
3. Вывод отзывов на сайте
